## Task 5 Fix Round 2：inode commit 与超短 current segment 恢复

### 结论

- Fragmented 正常 TERM：**PASS**，10.964 秒 AAC，可播放，非静音。
- Segmented 在 completed index `0` 完成、current index `1` 刚建立且只有 302 bytes 时 TERM：**PASS**，跳过不可导出 current，仅用 completed segment 恢复并保留 10 秒时间轴。
- Recovery claim 现在直接锁 working inode；publish 前在该 inode 上持久化 pending marker，publish 成功即为 commit。清理 working 失败不会把成功报成失败，marker 会阻止第二 target 重复发布。
